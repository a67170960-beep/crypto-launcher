# Crypto Launcher

Premium dark-blue **Minecraft Java** tooling for Android + **Crypto Client** Fabric mod (1.21.4).

## What works now

| Component | Status |
|-----------|--------|
| **Crypto Client** (Fabric 1.21.4) | Implemented: Right Shift menu, legit HUD/Visual/Utility/PvP info modules |
| **Crypto Launcher APK** | UI: profiles, servers, performance presets, dark theme |
| **Java ME runtime on Android** | **Not embedded yet** — requires open-source Pojav-class stack (GPL). See docs/LIMITATIONS.md |

## Design
Black / graphite / calm blue. No neon.

## Crypto Client
- Open menu: **Right Shift**
- Categories: Visual, HUD, Performance, Utility, PvP Legit, Misc
- No KillAura / AimBot / reach hacks / anti-cheat bypass

## Build
GitHub Actions builds:
- `crypto-client-jar`
- `crypto-launcher-apk`
